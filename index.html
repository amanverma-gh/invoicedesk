Questions

What happens when the free trial ends?

Your account is locked until the admin subscribes for $25 a year. Nothing is deleted: subscribe and everything is back exactly as you left it.

Is $25 per person?

No. It is $25 a year per business, however many team members you add.

Is the self-hosted version really free?

Yes. The full source code is on GitHub under the MIT license. Create a free Supabase project, run one SQL file and deploy the files to any static host.

Does it support GST and UPI?

Yes. Set your GST rate and GSTIN once. Add your UPI ID and each invoice shows a QR code with the exact amount due. Customers abroad can pay by Zelle, bank transfer or a payment link.

Where is my data stored on the cloud plan?

In a Supabase (PostgreSQL) database with row-level security, so each business can only ever see its own data.

Is the demo safe to play with?

Yes. It never touches our servers. Everything stays in your browser and is deleted automatically after one hour.
